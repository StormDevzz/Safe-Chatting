# Safe Chatting для Windows

## Сборка (простой способ — MSYS2)

1. Установи [MSYS2](https://www.msys2.org/)
2. Открой **MSYS2 UCRT64**
3. Установи всё нужное одной командой:
```
pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-openssl make
```
4. Собери:
```
cd c/windows
make
```

## Запуск

```
cd c/windows
build\chatserver.exe   ← сервер
build\chat.exe         ← клиент
```

## Как пользоваться

1. Запусти сервер на одном компьютере
2. Запусти клиент на двух разных терминалах (или компьютерах)
3. В клиенте: зарегистрируйся (R) или войди (L)
4. Пиши `@имя_пользователя текст` — сообщение уйдёт адресату
5. `/users` — список пользователей, `/exit` — выход

Сервер слушает порт 8080. Клиент по умолчанию стучится на 127.0.0.1:8080.
